# 五笔字根练习 · Wubi Practice

一个零依赖的单文件五笔字根训练应用。直接用浏览器打开 `index.html` 即可使用。

## 功能

### 三种练习模式
| 模式 | 内容 | 判分规则 |
|---|---|---|
| 字根 → 字母 | 给字根（如「木」）打对应键 | 支持一字根多键（`匚` → A 或 X 都算对） |
| 字母 → 字根 | 给键位（如「R」）写出任一正确字根 | 使用完整字根表判分，含变体/形近根 |
| 拆字打字 | 给汉字（如「好」）打出完整拆字键序列 `VB` | 按序列严格比对 |

### 字根数据
- 25 键全量字根，共 **165 个去重字根**
- 含变体与形近根：`革 丆 长 覀 且 罒 骨 彳 攵 𧘇 𠆢 ㇏ 冫 ⺍ 礻 衤 ⺗ 乚 臼 ス 母 丂` 等
- 归属已校正：`厂` → D、`犬` → D、`犭` → Q、`臼` → V …
- 60 字拆字题库
- 一字根多键使用 `ROOT_TO_KEYS` 数组维护

### 口诀助手（悬浮）
- 右下角 FAB 💡 + 可拖动浮层卡片，位置记忆
- 本题口诀带 `【一区 · 横】` 分区前缀
- 分区对照 1区～5区，可折叠
- 答错自动弹出；点击卡片外自动关闭（350ms 防误关）
- 移动端贴底全宽

### 学习机制
- 错题本 + 间隔重复：答错入本、答对降权归零移出，45% 概率优先抽错题，跨会话持久化
- 分区多选过滤（至少 1 区），三种模式均生效

### 计时系统
- 本次 / 今日 / 本周三档计时，周一到周日柱状图
- 空闲 30 秒自动暂停、离开页面暂停、手动暂停
- 5 秒增量落盘，`beforeunload` 兜底，90 天清理

## 使用方法

```bash
# 直接打开
open index.html
```

无需构建、无需依赖、无需服务器。
